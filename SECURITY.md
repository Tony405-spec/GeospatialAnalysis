# Security Policy

## Supported Versions

This repository is maintained from the default branch. Security fixes should target the default branch unless a release branch is created in the future.

## Reporting a Vulnerability

If you find a vulnerability or sensitive data exposure risk, please do not open a public issue with exploit details or private information.

Instead, contact the maintainer through the GitHub profile associated with this repository and include:

- A short description of the issue.
- The affected file, notebook, dataset, or workflow.
- Steps to reproduce when safe to share.
- Suggested remediation if known.

## Sensitive Data

Do not commit API keys, passwords, tokens, private certificates, or private geospatial datasets. If sensitive data is discovered in history, rotate the exposed secret and remove it from Git history using an appropriate remediation process.
